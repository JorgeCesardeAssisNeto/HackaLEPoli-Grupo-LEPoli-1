# Sessão 05: Inteligência Médica & RAG (Retrieval-Augmented Generation)

Sistemas de suporte à decisão clínica com LLM baseados em contexto temporal e diretrizes.

## Arquivos nesta Sessão:

### `interpretador_rag.py`
- **Origem no projeto:** `Etapa Exames de Sangue/interpretador_rag.py`
- **Descrição:** Pipeline de RAG clínico. Combina a evolução longitudinal do paciente com a base de conhecimento médico para gerar relatórios diagnósticos fundamentados.

### `gerador_conhecimento.py`
- **Origem no projeto:** `Etapa Exames de Sangue/gerador_conhecimento.py`
- **Descrição:** Indexador e compilador das bases de diretrizes e evidências médicas para enriquecimento do contexto do modelo de linguagem.
