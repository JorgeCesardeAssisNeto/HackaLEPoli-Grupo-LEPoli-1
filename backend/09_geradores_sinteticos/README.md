# Sessão 09: Geradores de Dados Sintéticos & Ferramentas Auxiliares

Simuladores de coortes clínicas, validação de sintaxe e criação de laudos hipotéticos realistas.

## Arquivos nesta Sessão:

### `gerador_laudos.py`
- **Origem no projeto:** `Etapa Exames de Sangue/gerador_laudos.py`
- **Descrição:** Gerador de laudos laboratoriais sintéticos em formato PDF com layout hospitalar idêntico a exames reais.

### `gerar_10_laudos.py`
- **Origem no projeto:** `Etapa Exames de Sangue/gerar_10_laudos.py`
- **Descrição:** Script orquestrador que simula o acompanhamento longitudinal de 3 anos de um paciente com 10 episódios laboratoriais consecutivos.

### `check_js_syntax.py`
- **Origem no projeto:** `Etapa Exames de Sangue/check_js_syntax.py`
- **Descrição:** Validador e linter sintático para scripts JavaScript embutidos em templates HTML.

### `validate_js.py`
- **Origem no projeto:** `validate_js.py`
- **Descrição:** Script complementar de teste e validação de lógica frontend.
